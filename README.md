# Tachiko Fortune

Tachiko Fortune is an original, modern city-strategy digital board game about movement, investment, risk, tactical interaction, and emergent stories.

It is inspired by the **broad genre appeal** of classic digital board/tycoon games, but it is **not a clone, remake, compatibility project, or asset-replacement project** for *Richman 4 / 大富翁 4* or any other commercial title.

The first planned vertical slice is a small, original **Tokyo-inspired** board for 2–4 human/AI participants.

## Initial technical direction

- Godot 4.x
- typed GDScript
- deterministic, command-driven simulation
- graph-based data-driven boards/content packs
- headless domain tests
- single-device vertical slice first
- multiplayer-ready boundaries, but no online infrastructure in v0
- Tachiko Work as a future optional authoring/control plane, not a runtime dependency

## Project rule in one sentence

A player may recognize the **genre**, but the rules expression, terminology, board, content, balance, code, UI, art, audio, and overall identity must be Tachiko Fortune’s own.
